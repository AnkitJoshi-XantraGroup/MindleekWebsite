## 🎨 Customization

### Changing Colors
Edit the CSS variables in `styles.css`:

```css
:root {
    --primary-color: #4B73FF;      /* Main blue */
    --secondary-color: #FF66F4;    /* Pink accent */
    --accent-color: #FE7B02;       /* Orange accent */
    --text-primary: #1A1A1A;       /* Main text color */
    --bg-primary: #FFFFFF;         /* Background */
}
```

### Updating Content
All content is in `index.html`. Simply edit the text between HTML tags:

```html
<h1 class="hero-title">We bring ideas to life with AI</h1>
```

### Adding Images
Replace placeholder divs with real images:

```html
<!-- Before -->
<div class="project-placeholder">AI Product</div>

<!-- After -->
<img src="images/your-image.jpg" alt="Description">
```

## 🐛 Troubleshooting

### Website doesn't load
- Check file names are exactly: `index.html`, `styles.css`, `script.js`
- Ensure files are in `public_html` folder
- Verify file permissions (644 for files)

### Styles not showing
- Confirm `styles.css` is in the same folder as `index.html`
- Clear browser cache (Ctrl+F5)
- Check for typos in file names

### JavaScript not working
- Verify `script.js` is uploaded
- Open browser console (F12) to check for errors
- Ensure file is in same folder as `index.html`
